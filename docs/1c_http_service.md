# HTTP‑сервис 1С для передачи затрат по котельным

Наш сервис в режиме `ONEC_MODE=http` раз в месяц дёргает один GET‑эндпоинт 1С и
получает суммы затрат по объектам за период. Ниже — готовый код HTTP‑сервиса на
основе вашего запроса (РегистрБухгалтерии.Хозрасчетный.ОборотыДтКт) и шаги публикации.

Почему именно так: стандартный OData 1С не отдаёт виртуальную таблицу
`ОборотыДтКт` (с фильтром по иерархии счетов и субконто), поэтому нужен небольшой
HTTP‑сервис, который выполняет ваш готовый запрос и возвращает JSON.

## Что должен вернуть сервис

`GET .../hs/costs/period?start=YYYY-MM-DD&end=YYYY-MM-DD` →

```json
{
  "items": [
    {"Объект": "с. Добрынское школа, бассейн", "СуммаОборот": 123456.78},
    {"Объект": "г. Киржач, СОШ №7, д/сад №40", "СуммаОборот": 98765.43}
  ]
}
```

`Объект` — то, что однозначно идентифицирует котельную из перечня (по умолчанию —
ПодразделениеЗатрат; если котельная у вас = НоменклатурнаяГруппа, см. комментарий в коде).
`СуммаОборот` — сумма затрат за период (ваш `СУММА(...СуммаОборот)`).

## Код модуля HTTP‑сервиса (вставить в Конфигураторе/расширении)

Создайте объект **HTTP‑сервис** `costs`: Корневой URL — `costs`; шаблон URL — `/period`;
метод HTTP — `GET`; имя метода обработчика — `periodGET`. Модуль:

```bsl
Функция periodGET(Запрос)

    Пар = Запрос.ПараметрыЗапроса;
    ДатаНачала    = ПреобразоватьДату(Пар.Получить("start"));
    ДатаОкончания = КонецДня(ПреобразоватьДату(Пар.Получить("end")));

    Запрос1 = Новый Запрос;
    Запрос1.Текст =
    "ВЫБРАТЬ
    |   ХозрасчетныйОборотыДтКт.ПодразделениеДт КАК Объект,
    |   СУММА(ХозрасчетныйОборотыДтКт.СуммаОборот) КАК СуммаОборот
    |ИЗ
    |   РегистрБухгалтерии.Хозрасчетный.ОборотыДтКт(
    |       &ДатаНачала,
    |       &ДатаОкончания,
    |       Регистратор,
    |       СчетДт В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ОсновноеПроизводство)), ,
    |       СчетКт В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.СырьеИМатериалы)), , ) КАК ХозрасчетныйОборотыДтКт
    |СГРУППИРОВАТЬ ПО
    |   ХозрасчетныйОборотыДтКт.ПодразделениеДт";
    // Если котельная в учёте = НоменклатурнаяГруппа, замените в двух местах
    // ПодразделениеДт на СубконтоДт1.

    Запрос1.УстановитьПараметр("ДатаНачала", ДатаНачала);
    Запрос1.УстановитьПараметр("ДатаОкончания", ДатаОкончания);

    Выборка = Запрос1.Выполнить().Выбрать();
    Массив = Новый Массив;
    Пока Выборка.Следующий() Цикл
        Элемент = Новый Структура;
        Элемент.Вставить("Объект", Строка(Выборка.Объект));
        Элемент.Вставить("СуммаОборот", ?(Выборка.СуммаОборот = Неопределено, 0, Выборка.СуммаОборот));
        Массив.Добавить(Элемент);
    КонецЦикла;

    Результат = Новый Структура("items", Массив);

    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.УстановитьСтроку();
    ЗаписатьJSON(ЗаписьJSON, Результат);
    ТелоОтвета = ЗаписьJSON.Закрыть();

    Ответ = Новый HTTPСервисОтвет(200);
    Ответ.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
    Ответ.УстановитьТелоИзСтроки(ТелоОтвета, КодировкаТекста.UTF8);
    Возврат Ответ;

КонецФункции

Функция ПреобразоватьДату(Знач Текст)
    // Ожидаем "YYYY-MM-DD"; пусто -> начало времён
    Если Текст = Неопределено ИЛИ Текст = "" Тогда
        Возврат '00010101';
    КонецЕсли;
    Текст = СтрЗаменить(Текст, "-", "");

КонецФункции
```

Рекомендация: заведите сервис в **расширении конфигурации**, чтобы не менять типовую.

## Публикация

1. Конфигуратор → Администрирование → **Публикация на веб‑сервере** → на вкладке
   HTTP‑сервисы включить публикацию сервиса `costs` (галочка).
2. Дать пользователю (`odata.costs` или отдельному) право на этот HTTP‑сервис.
3. Проверить в браузере/curl:
   `http://hq.tsfera.ru:62080/b_tsfic_f_3/hs/costs/period?start=2026-07-01&end=2026-07-31`
   (должен вернуться JSON выше).

## Переменные окружения для нашего сервиса (панель Amvera)

| Переменная | Значение | Секрет |
|---|---|---|
| `ONEC_MODE` | `http` | нет |
| `ONEC_BASE_URL` | `http://hq.tsfera.ru:62080/b_tsfic_f_3` | нет |
| `ONEC_HTTP_PATH` | `/hs/costs/period` | нет |
| `ONEC_USERNAME` | пользователь сервиса (напр. `odata.costs`) | нет |
| `ONEC_PASSWORD` | пароль пользователя | **да** |
| `ONEC_FIELD_OBJECT` | `Объект` (по умолчанию) | нет |
| `ONEC_FIELD_AMOUNT` | `СуммаОборот` (по умолчанию) | нет |

После публикации сервиса задать эти переменные и перезапустить приложение —
затраты начнут подтягиваться в отчёт. Соответствие названий котельных ЛЭРС ↔ 1С
делается автоматически по нормализованным названиям (`onec_client.match_costs`);
несопоставленные строки видны в колонке «Примечание».
